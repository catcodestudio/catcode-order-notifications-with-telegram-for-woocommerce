# CatCode Order Notifications with Telegram for WooCommerce

Instant Telegram notifications for WooCommerce orders and site form leads: new orders, status changes, failed payments, low stock, Contact Form 7.

This repository mirrors the free version published on wordpress.org, version 1.3.1.

## Requirements

- WordPress 6.2+ (tested up to 7.1)
- WooCommerce 6.0+ (tested up to 10.7)
- PHP 7.4+

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for the plugin name), or download this repository and upload it to `wp-content/plugins/catcode-order-notifications-with-telegram-for-woocommerce/`.
